# Sumrace

Fifteen maths & logic puzzles, one clock — daily sets, races, and
wearable maths. No sign-ups, no downloads.

🧮 Play: **[sumrace.com](https://sumrace.com)**

## Open source

- **[puzzle-generators](https://github.com/sumracedaily/puzzle-generators)** — seeded generators for Number Pyramid, Kakuro and friends
- **[seedrand](https://github.com/sumracedaily/seedrand)** — tiny seeded RNG; `dailySeed()` gives every player the same sequence each UTC day
- **[phys-mini](https://github.com/sumracedaily/phys-mini)** — minimal 2D physics for canvas games: gravity, impulse collisions, bounds
